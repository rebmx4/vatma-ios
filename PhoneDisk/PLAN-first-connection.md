# План для Сола · «Мой диск» на собственном ПК

**Результат для пользователя.** Человек открывает `https://rynpro.ru/disk/`, устанавливает приложение на iPhone и программу на Windows, выбирает свою папку и сканирует код с монитора. На iPhone открывается вкладка «Файлы» с этой папкой. Для первого подключения достаточно домашней сети. Весь путь доступен без регистрации, командной строки, ввода IP и настройки роутера.

## 1. Подготовить мастер на сайте

На `/disk/` сейчас открывается «Демо „Моего диска“». Сделать основной кнопкой «Подключить мой компьютер», рядом сохранить вход «Открыть демо» с тестовыми файлами. Подготовить изменения на тестовой копии. Проверить действующие ссылки на демо до публикации.

Показать четыре шага, по одному действию на экран. Одинаковые названия кнопок должны встречаться на сайте и в программах.

1. **Установи «Мой диск» на iPhone.** Показать действующую ссылку для этой аудитории. В пилоте она ведёт в TestFlight, после публичного выпуска — в App Store.
2. **Установи «Мой диск» на Windows.** На ПК показать кнопку «Скачать для Windows». На телефоне подсказать, что на компьютере нужно открыть тот же адрес `rynpro.ru/disk/`.
3. **Выбери папку на компьютере.** Показать кнопку «Добавить папку» и короткий пример с папкой «Видео». Файлы остаются на своих местах.
4. **Подключи iPhone.** На ПК нажать «Подключить телефон», на iPhone — «Добавить компьютер» и навести камеру на QR-код с монитора. Результат показать в самих программах. На iPhone видна папка «Видео», на ПК — подключённый телефон.

Для инструкций использовать экраны готовых программ. Сохранить согласованный стиль приложения с чёрным фоном, компактными элементами и зелёным акцентом. Сайт раздаёт инструкцию и установщик. Содержимое пользовательских папок передаётся между устройствами.

## 2. Подготовить программу для Windows

- Собрать установщик со всеми нужными компонентами и простым окном управления. Службу, конфигурацию и ключи разместить на системном диске. Поддержать автозапуск, обновление с сохранением привязок и временное отключение съёмного диска с файлами. Для публичного скачивания подготовить подписанный установщик.
- При первом запуске у нового ПК пустой список общих папок. Владелец выбирает папки через обычное окно Windows. Отдельно указывает папку для автокопий, если хочет принимать фото и видео с iPhone.
- У каждого ПК свои идентификатор и ключ. В окне «Подключить телефон» ПК создаёт одноразовое приглашение с коротким сроком действия. Код генерируется локально. Повторное сканирование использованного или просроченного кода предлагает показать новый.
- В окне «Подключённые устройства» владелец видит телефоны, меняет доступные каждому папки и может отозвать доступ. Разделить просмотр и скачивание, запись и удаление. Проверять разрешения на ПК при обращении к файлу, обложке, видеопотоку и передаче.

## 3. Привязать iPhone к выбранному ПК

- В приложении уже есть обнаружение Bonjour `_phonedisk._tcp`, проверка `serverId` и фоновые сеансы передачи. Сейчас базовый адрес `files.rynpro.ru` и список источников зафиксированы в коде. Начать с `App/DiskRoutes.swift`, `App/Transfers.swift`, `App/ResumableTransfers.swift` и выбора папок в `App/PhoneDiskApp.swift`. Журнал передач и история автокопий находятся в `App/TransferLedger.swift` и `App/BackupHistory.swift`.
- Сделать профиль сопряжённого ПК. После сканирования сверить ключ ПК с отпечатком из QR по защищённому соединению, однократно погасить приглашение и выдать отдельные учётные данные телефону. Сохранить их в Keychain. При следующем запуске автоматически находить этот ПК, в том числе после смены локального IP. Если рядом обнаружены два компьютера, показать папки того, чей код отсканирован.
- Получать доступные папки и назначения автокопий от сопряжённого ПК. Связать веб-интерфейс, просмотр видео, очередь, учётные данные и историю автокопий с тем же профилем. При обновлении существующей установки перенести её сохранённую привязку и задания. На новой установке первой открывать кнопку «Добавить компьютер».
- Дома сначала проверять прямое соединение iPhone с локальным IP выбранного ПК. Если проверка прошла, использовать его для файлов в обе стороны, даже при включённом Tailscale. Если ПК недоступен локально, проверить уже настроенный Tailscale этого же ПК. При отсутствии обоих маршрутов показать «Компьютер недоступен» и дать повторить подключение. Сайт и VPS владельца в передаче файлов не участвуют.
- Запрашивать доступ к камере и локальной сети в момент подключения. Если доступ запрещён, объяснить, какое разрешение включить, и дать повторить текущий шаг. [Локальная сеть в iOS, документация Apple](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)

## 4. Добавить защиту «Файлов»

После подключения предложить включить Face ID или системный код iPhone. Защиту можно включить позже в настройках. Использовать `LocalAuthentication` с `deviceOwnerAuthentication` и добавить описание использования Face ID в `Info.plist`. После запуска и возврата из фона требовать разблокировку перед показом списка или открытого файла. Скрывать содержимое в переключателе приложений. Отмена проверки оставляет «Файлы» закрытыми. Для отключения защиты тоже нужна проверка. [Системная проверка владельца устройства](https://developer.apple.com/documentation/localauthentication/lapolicy/deviceownerauthentication)

Отделить разблокировку интерфейса от обслуживания очереди. Уже начатые скачивания и выгрузки должны продолжаться при сворачивании и блокировке экрана. [Фоновые передачи в iOS](https://developer.apple.com/documentation/foundation/downloading-files-in-the-background)

## 5. Проверить перед выпуском

| Проверка | Что должно получиться |
| --- | --- |
| Первое подключение | На чистом Windows-ПК и физическом iPhone человек проходит инструкцию без подсказок разработчика. В «Файлах» видна только выбранная папка. Видео показывает обложку, воспроизводится и скачивается. |
| Два независимых ПК в одном Wi-Fi | Каждый телефон открывает папки своего ПК. Новый пользователь не попадает на компьютер владельца проекта. Изменение IP после перезагрузки не требует повторного сканирования. |
| Приглашения и права | Использованный или просроченный QR не подключает новый телефон. Папка только для чтения запрещает запись и удаление. После отзыва устройство теряет доступ при новом запросе, включая запрос по ранее полученной ссылке. |
| Домашняя и удалённая сеть | Передать файл 3 ГБ по домашнему Wi-Fi при включённом Tailscale, записать фактический маршрут, время, среднюю скорость и сверить файл. Вне домашней сети повторить передачу через настроенный Tailscale. |
| Face ID и фон | Проверить вход по лицу, по системному коду и отмену. Свернуть приложение и заблокировать iPhone во время скачивания и выгрузки. Сверить завершение и целостность файлов на принимающей стороне. |
| Обновление владельца и автокопии | Проверить переход с 1.0.0 (71), существующие папки, очередь и историю. Старая и новая фотография и видео должны попасть в выбранную папку автокопий без ограничения по дате и повторной отправки уже сохранённых файлов. |

**Порядок поставки.** Сначала показать тестовую страницу, проверить установщик на чистом Windows-ПК и проверить обмен одноразового приглашения на доступ к одной папке тестовым клиентом. Для системного Face ID и выбора ПК в фоновых передачах нужен нативный код. Объединить изменения iOS в один кандидат и согласовать конкретную сборку и загрузку в TestFlight с владельцем до их запуска. На согласованной версии пройти проверки из таблицы с физическим iPhone. Публичные кнопки скачивания включать, когда по обеим ссылкам человек действительно может получить совместимые версии.
