# Рабочий стол и приватный стол — 3 ноября 2026

- Двойное касание пустого места перемещает ярлыки каждой публичной страницы к противоположному вертикальному краю, сохраняя порядок и промежутки. Следующее двойное касание восстанавливает исходные позиции. Ручное перемещение после сдвига становится новой исходной раскладкой.
- Ярлык «Приватный стол» расположен на второй публичной странице по умолчанию и может быть перемещён. Приватные страницы появляются только после разблокировки. Папка с единственным оставшимся ярлыком распускается, ярлык занимает её ячейку.
- При первой настройке приватного стола доступны шестизначный код, биометрия либо оба способа, если Face ID или Touch ID настроены на устройстве. Три неверных кода блокируют ввод на 30 секунд. Биометрия предлагается после ошибок только там, где была предварительно включена.
- Данные ярлыков приватного стола шифруются AES-GCM. При биометрическом входе ключ хранится в Keychain с `biometryCurrentSet` и `WhenPasscodeSetThisDeviceOnly`. Биометрический ключ не переносится на другое устройство; изменение набора биометрии или отключение кода устройства может лишить доступа к столу. Замок стола не скрывает историю посещений и входы на сайты.
- Обычные вкладки и сохранённые веб-приложения используют общий постоянный `WKWebsiteDataStore`. Срок сеанса задаёт сайт; приложение не может гарантировать бессрочный вход.

Проверено: 114 JS-тестов и статическая проверка 282 файлов. Компиляция Swift, работа Keychain, жесты и сохранение входа на iPhone/iPad пока не проверены. Эти правки отсутствуют в опубликованной сборке.
