# Блокировка ATMA

Нативная iOS-основа использует собственный модуль `SiteBlocker` и встроенный
`BrowserUI/content-blocker.json`. Это исходный каталог ATMA из 27 правил для
сторонних рекламных и измерительных доменов, без копирования кода или списков Brave.
Правила исполняет Apple WebKit через WKContentRuleList. Никакого отдельного движка,
сервиса или подписки блокировщика в этой реализации нет.

В настройках открытого сайта предусмотрен переключатель. Исключение сохраняется
только для точного hostname; переход на другой сайт восстанавливает его собственную
политику. Блокировка не изменяет проверки TLS, cookies или загрузки файлов.

Этот каталог — начальная доменная блокировка. Он не обеспечивает функциональную
полноту Shields/uBlock: нет scriptlets, косметических фильтров, фильтрации рекламы,
выдаваемой самим сайтом, или обещания убрать рекламу YouTube. Общедоступные списки
других проектов сейчас не включены; их можно подключить отдельно с соблюдением
лицензии. Обновление встроенных правил требует новой подписанной сборки.

27 правил проверены как JSON и по границам hostname; компиляция WKContentRuleList,
реальная блокировка и исключения требуют Xcode/iPhone. Windows-предпросмотр через
Responsively не использует этот нативный модуль, поэтому не выдаёт его за работающую
блокировку в Windows.
