# Блокировка ATMA

Нативная iOS-основа использует собственный модуль `SiteBlocker` и встроенный
`BrowserUI/content-blocker.json`. Это исходный каталог ATMA из 27 правил для
сторонних рекламных и измерительных доменов, без копирования кода или списков Brave.
Правила исполняет Apple WebKit через WKContentRuleList. Никакого отдельного движка,
сервиса или подписки блокировщика в этой реализации нет.

В этой версии правила применяются без переключателя и без списка исключений в
интерфейсе. Фильтрация не изменяет проверки TLS, cookies или загрузки файлов.

Этот каталог — начальная доменная блокировка. Дополнительный адаптер YouTube
обрабатывает некоторые рекламные поля плеера, но не гарантирует удаления всей
рекламы. Полноты Shields/uBlock здесь нет: отсутствуют общие косметические фильтры,
scriptlets и полноценные правила для рекламы, выдаваемой самим сайтом.
Общедоступные списки других проектов сейчас не включены. Обновление встроенных
правил требует новой подписанной сборки.

27 правил проверены как JSON и по границам hostname; компиляция WKContentRuleList
и реальная блокировка требуют Xcode/iPhone. Windows-предпросмотр через
Responsively не использует этот нативный модуль, поэтому не выдаёт его за работающую
блокировку в Windows.
