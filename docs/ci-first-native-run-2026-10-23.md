# ATMA: первый нативный прогон и исправления

По прямому разрешению владельца выполнен один прогон Codemagic M2:
[6adbc2984a72334e32e4866d](https://codemagic.io/app/6a1af30432a4361359ee5663/build/6adbc2984a72334e32e4866d).
Проверялась версия `431354b192a4847ec8db366b7bda752541915411` ветки `atma-browser-testflight`.
Прогон завершился ошибкой, подписанная сборка и отправка в TestFlight не запускались.

## Проверенные результаты

- Codemagic: 23 октября 2026, 20:25:06–20:39:19 UTC, около 14 минут 13 секунд.
- Подготовительные Python/JavaScript и проверки исходников прошли.
- Нативные исходники и тестовые цели скомпилировались на Xcode 26.4.1.
- XCTest на iPhone **не запускались**: Bash сообщил `options[@]: unbound variable`.
  Пустой массив аргументов под `set -u` не совместим с системным Bash на Mac;
  ошибка раскрытия в конвейере не остановила этот шаг.
- На iPad выполнился один UI-тест и завершился ошибкой ожидания Home.
  Иерархия UI содержит `ATMA UI could not start` и `Network.NWError ... 22 ... Invalid argument`.
  Журнал приложения уточняет: `Local endpoint has port set, cannot override`.
- Успешного результата нативных unit tests нет. Нельзя считать компиляцию их выполнением.

## Изменения после прогона

- `LocalUIServer` передаёт адрес и порт только через `requiredLocalEndpoint`.
  Повторный аргумент `on:` удалён; привязка остаётся на `127.0.0.1`.
  [Контракт NWListener](https://developer.apple.com/documentation/network/nwlistener/init(using:on:))
  допускает вызов без необязательного аргумента порта.
- CI собирает непустой массив всей команды `xcodebuild`, затем добавляет фильтр iPad.
  Для iPhone сохраняется запуск всех unit/UI tests, для iPad — UI smoke.
- Добавлены три проверки реального shell-сценария с подменёнными Apple-инструментами:
  обе проверки устройств; остановка после ошибки iPhone; остановка после ошибки iPad.
  Отметка проверенного коммита появляется только при успешном окончании.
- Артефакты сохраняют также текстовую и видео-диагностику XCTest.
- Для shell-файлов закреплён LF, в том числе при checkout на Windows.

## Проверка исправлений и остаток

- `python -B -m unittest discover -s tests -v`: 13/13, включая три новых сценария.
- `bash --noprofile --norc -n release/ci.sh`: синтаксис принят.
- Статическая валидация приложения: 263 файла, без ошибок.
- Поведение исправленного сервера на Apple runtime пока не подтверждено:
  существующий упавший UI-тест необходимо повторить на Mac.
- Следующий нативный прогон требует отдельной команды владельца по сохранённому
  правилу запуска каждой сборки. При успехе затем нужна подписанная сборка этой же
  версии и обработка Apple; ручные проверки Google/YouTube на телефоне остаются.

Журналы и исходный xcresult сохранены на D: в `out/launch-20261023-*`;
извлечённая диагностика — `out/ci-evidence-20261023/`. Новых сборок при разборе не запускали.
