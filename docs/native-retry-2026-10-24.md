# ATMA: повторный нативный прогон и карточка Apple

Владелец выбрал существующую карточку ATMA `6774934498`, bundle ID `ru.atma.app`.
Новая карточка и новый идентификатор не создавались.

## Apple

В открытом App Store Connect прочитан ответ Apple от 18 июня 2026 года:
пункт 4.3(b), повторяющиеся астрологические/предсказательные функции прежнего приложения.
Указания сменить Bundle ID в сообщении нет; Apple предлагает пересмотреть концепцию
и ожидает повторную отправку приложения. Одобрение браузера этим не подтверждено.

По разрешению владельца в черновике русской версии сохранены описание браузера,
рекламный текст, ключевые слова и примечания для проверки. Сохранение подтверждено
чтением полей после перезагрузки страницы. Снимки экрана, ссылки, возрастной рейтинг,
категория и остальные сведения требуют сверки перед окончательной отправкой.
Старый выбранный build 8 необходимо заменить успешно проверенной сборкой браузера.
Ни обновление отправки, ни повторная отправка на App Review не выполнялись.
Исходный текст черновика и его привязка к версии находятся на D: в
`out/apple-browser-metadata-20261024.json`.

## Следующая правка

- User-Agent сравнивается с новым системным WKWebView, а не с представлением `nil`.
  Проверки явных desktop/mobile UA и content mode сохраняются.
- UI и страницы сайтов получили идентификаторы `atma.ui` и `atma.site.<tabID>`.
  UI-тест проверяет отсутствие site renderers на Home и пустой вкладке, их наличие
  при открытом HTTPS-сайте и отсутствие после перезапуска.
- Отдельный native test восстанавливает сохранённую вкладку с HTTPS-адресом
  и проверяет пустой словарь renderers сразу после загрузки контроллера на Home.
  Асинхронную загрузку интерфейса этот unit test не ожидает; сценарий перезапуска
  с проверкой UI остаётся в smoke test.
- Добавлены проверка доступности Home и ранние снимок экрана/иерархия UI.
  Сценарии настроек, сайта и перезапуска не удалялись.
