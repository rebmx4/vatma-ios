# Независимая ATMA для iOS

Владелец 23.10.2026 потребовал исключить всю базу и сервисы Brave из активного
приложения. Используем UIKit/WebKit Apple и собственный интерфейс ATMA из
Responsively. Старый веб-клиент vatma.ru не является браузером и не используется.

Удалены из активного продукта: Wallet/crypto, Leo/AI, Rewards/BAT, News, VPN,
Talk/Jitsi, Playlist, покупки/подписки, P3A/телеметрия и Brave Account. В активной
сборке отсутствуют BraveCore, Chromium build, SDK/серверы Brave и их ключи.

Сохраняются рабочий стол, страницы, папки, PIN, оформление, вкладки, история
переходов, закладки-ярлыки, выбор поисковика/профиля, cookie и обычные загрузки.
«Файлы» содержит отдельный раздел Cookie: сайт, имя, значение, путь, срок и
флаги; удаление выбранных либо всех cookie текущего профиля. Значения не
попадают в журналы, отчёты, Git или дополнительные файлы экспорта.

`BrowserUI` — единый источник интерфейса; локальный preview использует его
через junction на D:. Native bridge доступен только собственному UI webview,
не сайтам. Страницы используют отдельные WKWebView и устойчивое хранилище
по профилям. Минимум iOS 17 для публичного API отдельных persistent data stores.
Локальный HTTP-сервер слушает только loopback; UI origin сохраняется между
запусками для localStorage/зашифрованной PIN-страницы.

TLS проверяется Apple; закреплённый российский RSA-корень добавляется только
к проверке приложения с сохранением SSL policy, системных корней, срока и имени.
Загрузки перечисляются из Documents/Downloads с проверкой путей и безопасными ID.

Этот переход не объявляет готовыми ещё не реализованные синхронизацию с ПК,
фоновые уведомления произвольных сайтов, полный fingerprint spoofing и перевод
страниц. Нужные функции остаются в требованиях для последующей реализации.
Блокировка рекламы должна иметь независимые от Brave правила WebKit.

Вся работа на Windows, инструменты, временные файлы и результаты только на D:.
Платные сборки/публикации не запускать. Проверки Windows не заменяют компиляцию
и сценарии на Apple Simulator/устройстве. Оценки длительности не являются замером.
