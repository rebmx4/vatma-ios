ATMA is a standalone, general-purpose browser for iPhone and iPad built with UIKit and WKWebView. This version contains browser features only and does not require an ATMA account.

All ATMA features are free. There are no ATMA in-app purchases, subscriptions, advertising SDKs or third-party analytics SDKs. Accounts and paid services offered by websites are controlled by those websites.

Review steps (no demo account required):
1. Launch ATMA to see the start page with website shortcuts. The ATMA home button returns to this page.
2. Tap plus, enter https://rebmx4.github.io/vatma-ios/guide.html and tap Go. This is a public help page and requires no login.
3. Ordinary tabs and saved shortcuts use system WebKit on the actual iPhone or iPad and share one persistent website data store. Incognito tabs use a separate nonpersistent store and offer a User-Agent/mobile-or-desktop website mode selector. This does not change the device or WebKit engine.
4. Save the open site using the add button beside the address, return to ATMA Home, and open the saved shortcut. It uses a compact bottom toolbar. Shortcuts and folders exist only inside ATMA; they do not install other iOS apps or replace the system Home Screen.
5. Open another page in a new tab and use the tab counter to inspect tab previews. The Cookies desktop icon lists websites, local data types and cookies without secret values. Settings contains Downloads, Appearance, Privacy Policy, Support and Media player.

6. Tap Open Incognito in Settings to open its white search screen and website device-mode selector. Private tabs are excluded from session restoration and use a temporary website store; ending the private session closes all private tabs. Home returns to the ordinary desktop, where saved shortcuts retain ordinary sign-ins. Deliberately saved files and shortcuts remain.

The privacy policy and support text are bundled in the app and also available at the supplied public URLs. The six-digit PIN protects only a separate page of saved links; it is not anonymous browsing or protection of the entire browser.

The browser applies WebKit content rules to known advertising requests and a YouTube advertising adapter. This may affect individual sites; Safari can be used as a comparison if a site behaves differently. Compatible media use the website player and public iOS media/Picture in Picture controls. Availability depends on the website and iOS. The app does not extract media download links or offer an offline media library. Websites retain their own terms and sign-in requirements.
